Projects

1. Lead Qualification Agent Done, demo ready

Problem: A business gets a long lead list and does not know who to contact first.

Solution: The agent scores each lead 0-100 for email, phone, website, industry fit, and location, grades it A / B / C, and drafts a short personalised first email for A and B leads. No price in the first email. No contact is guessed.

Demo result: On a 5-lead sample, 2 leads scored 100, 2 scored 80, and 1 scored 50 for missing data.

Tech: Python, FastAPI, CSV

2. Document RAG Agent Done, demo ready

Problem: A business has documents but no quick way to find the right answer in them.

Solution: Ask a question over your own documents and get an answer quoted from those documents, with the source file, section and score. If nothing matches, it says "No relevant section found" instead of guessing.

Demo result: Tested on 3 fictional sample documents, including the refund policy (14 days, unused part only after full delivery) and the starter package ($200/month in the fictional example).

Tech: Python, FastAPI, keyword / TF-IDF retrieval

Honest limit: this demo does not use an LLM; answers are quotes from the documents, not generated text.

3. Multi-Agent Research and Outreach Workflow Done, demo ready

Problem: Research, drafting and checking are usually done by hand, one after another.

Solution: Three agents in sequence: Researcher finds only notes that exist in the sample data, Writer drafts from those facts only, and Reviewer fails a draft that contains a price not in the facts, a guessed email, a guaranteed-result claim, a missing fact, or more than 200 words.

Demo result: Tested on "lead generation" for "small cafes" with reviewer PASS.

Tech: Python, FastAPI

Honest limit: these are rule-based functions, not LLM agents.

4. MCP and FastAPI Tool Agent Done, demo ready

Problem: An agent that only answers from memory cannot complete real work.

Solution: The agent picks a tool from its registry and returns the tool's actual result, with the tool name stated. Tools: score_lead, search_docs, draft_email, add_numbers.

Demo result: Tested lead scoring (100/A), document search, and add 12+30+8=50.

Tech: Python, FastAPI, MCP-style tool manifest

Honest limit: tools run as local Python functions behind an MCP-style manifest; this is not yet a full MCP server transport.
