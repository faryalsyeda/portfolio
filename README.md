# Portfolio Site - Outline and First Version

This is the first version of Faryal Syeda's AI portfolio site.

## What is inside
- index.html: the full portfolio site in one file, easy to upload to GitHub.
- Sections: About, Services, Projects, Skills with proof, Contact.
- Project 1 is complete: Lead Qualification Agent, with demo result.
- Projects 2-4 are now complete and linked: Document RAG Agent, Multi-Agent Research and Outreach Workflow, and MCP and FastAPI Tool Agent.
- Dockerfiles are in all 4 projects on GitHub, and CI workflow files are now in all 4 projects at `.github/workflows/ci.yml` on GitHub, added via the GitHub website because Muse's GitHub App cannot push workflow files.

## How to use it on GitHub
1. Connect GitHub in Muse and choose the repository for the portfolio.
2. Upload index.html (and later the Lead_Qualification_Agent folder) to that repository.
3. Add the exact LinkedIn and GitHub profile URLs in the Contact section before sharing it publicly.
4. After each new project is built, update its card from Planned to Done and add its GitHub link.
